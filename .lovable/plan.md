

# Page 1: Pricing & Tiers Page for Recruitment Platform

This page will serve as the pricing and feature comparison page for your job posting service, designed to match the clean, professional aesthetic of the existing joblet.ai platform.

---

## Page Structure

### Header Navigation
A consistent navigation bar matching your existing site design:
- **Left**: joblet.ai logo
- **Center**: Find Jobs | Post a Job | Blogs navigation links  
- **Right**: Sign In button (outlined) + Get Started button (coral/orange filled)

---

### Section 1: Hero Banner (Top 1/3 of page)

**Visual Design:**
- Full-width hero section with a placeholder image area
- The placeholder will be ready for you to replace with a custom image showing happy recruiters celebrating with resumes and analytics dashboards in the background
- Optional headline overlay (e.g., "Hire Smarter, Faster") with a subtle gradient

---

### Section 2: Pricing Tier Comparison (Bottom 2/3 of page)

**Layout:** 4-column comparison grid

| Features Column | Starter | Growth | Premium |
|-----------------|---------|--------|---------|
| Feature labels  | ✓/✗ + details | ✓/✗ + details | ✓/✗ + details |

**Features being compared:**

1. **Post Jobs for Free** → ✓ ✓ ✓ (all tiers)

2. **Ads via Meta & Google** → ✓ ✓ ✓ (all tiers)

3. **Analytics Dashboard** → Different text per tier:
   - Starter: "Applies, Applicant details, Click tracking"
   - Growth: "Applies, Applicant details download, Click tracking"
   - Premium: "Full access: Applies, Downloads, Clicks, Meta & Google Impressions"

4. **Auto-generated Images** → ✗ ✓ ✓

5. **Auto-generated Videos** → ✗ ✗ ✓

6. **Clicks** → Dynamic number based on timeline selection (placeholder values for now)

7. **Price** → Dynamic based on timeline selection (placeholder values)

---

### Timeline Selector (within each tier column)

Each tier will have an interactive selector with 3 options:
- **15 days**
- **30 days** 
- **45 days**

When a timeline is selected, the Clicks count and Price will update accordingly (using placeholder values for now).

---

### Call-to-Action Buttons

Each tier column ends with a prominent **"Choose Plan"** or **"Get Started"** button to select that tier.

---

## Design Consistency

- Clean white background with subtle gray borders
- Rounded cards matching the joblet.ai style
- Coral/orange accent color for primary buttons
- Professional typography with clear hierarchy
- Responsive design for mobile and desktop

---

## Technical Notes

- The hero image will be a placeholder that you can easily swap out later
- Timeline selections will dynamically update click counts and pricing
- All values for clicks and pricing will be placeholders that can be updated
- The page will be set up at the index route for now
